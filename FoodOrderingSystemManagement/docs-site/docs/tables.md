# Tables

The Tables screen gives a floor-plan-style view of dine-in seating.

## What you'll see

- **Table cards** grouped by hall, each showing live status (Available, Occupied, Reserved, etc.) with a colored indicator.
- **Tap a table** to view its current order, or start a new one directly from the table.
- **Reservations** — book a table ahead of time for a customer.
- **QR codes** — generate a per-table QR code that customers can scan to view the digital menu.
- **Multiple halls** — organize tables into separate seating areas (e.g. indoor / outdoor / rooftop).
