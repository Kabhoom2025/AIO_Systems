# Kitchen Display (KDS)

The Kitchen Display System shows the kitchen's live order queue — no paper tickets needed.

## What you'll see

- **Preparing** and **Ready** columns per order, so kitchen staff know exactly what's next and what's done.
- **Elapsed time** per order, so nothing sits forgotten.
- **Delay markers** — flag an order as delayed by a set number of minutes if it's running behind.
- **Kitchen notes** — attach a note to an order (e.g. "no onions") visible to the whole kitchen team.
- **Print slip** — print a kitchen order ticket (KOT) for stations without a screen.
- **Reject items or orders** — with a reason, which notifies the front-of-house instantly.
- **Live updates** — new orders appear the moment they're placed at the POS, via the same real-time connection Orders uses.
