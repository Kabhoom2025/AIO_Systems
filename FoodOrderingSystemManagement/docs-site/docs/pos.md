# Point of Sale (POS)

The POS screen is where staff take orders — walk-in, dine-in, or takeaway.

## What you'll see

- **Category tabs** across the top to browse the menu.
- **Food item grid** — tap an item to add it to the current order; items with add-ons prompt for choices before adding.
- **Order panel** on the side — running list of items, quantities, and the live subtotal/tax/total.
- **Order type** — Dine-in (with table selection), Takeaway, or Delivery.
- **Discounts** — flat amount or percentage, applied before generating the bill.
- **Generate & Print Bill** — finalizes the order and opens the [receipt](./printer-setup) for printing.
- **Loyalty** — returning customers can redeem or earn points automatically based on the order total.
