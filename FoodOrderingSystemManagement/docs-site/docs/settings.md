# Settings

Settings is where an Admin configures how the restaurant's copy of FoodOrder POS behaves. It's organized into expandable panels:

- **General** — restaurant name, address, phone, logo, and GST number (shown on receipts).
- **Tax** — tax percentage, tax name, and whether prices are tax-inclusive.
- **POS** — default order type, auto-print bill on order, tips, and whether a customer phone number is required.
- **Menu** — whether to show item images, descriptions, and out-of-stock items on the ordering screen.
- **Printer** — enable/disable printing, printer type, and network printer IP/port. See [Printer Setup](./printer-setup) for connecting a USB or Zebra printer directly.
- **Payment Gateway** — enable cash, card, and online payments; Razorpay keys for online payments.
- **Email** — SMTP configuration for outgoing emails (receipts, password resets).
- **Backup** — automatic backup schedule and notification email.
- **Theme** — primary color and light/dark mode default.
- **Feature Toggles** — turn entire modules on/off (Online Ordering, Table Reservations, Loyalty Program, SMS/WhatsApp alerts, Delivery, Kitchen Display, Promotions & Coupons).
- **Integrations** — third-party services (delivery partners, analytics, CRM, accounting, ERP) and SSO login providers.
