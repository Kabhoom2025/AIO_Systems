# Orders

The Orders screen lists every order — active and historical — with tools to track and manage them.

## What you'll see

- **Active Orders** and **History** tabs — active orders (Pending, Served, Bill Pending) vs. completed/cancelled ones.
- **Filters** — by order type (All / Dine-in / Takeaway) and status (Pending, Served, Bill Pending, Completed, Cancelled).
- **List and grid views** — switch layout depending on how many orders you're scanning.
- **Search** — find an order by number or customer.
- **Per-order actions** — view the receipt, update status, or cancel, depending on your permissions.
- **Live updates** — new orders and status changes from the kitchen appear automatically without refreshing (powered by a real-time connection to the server).
